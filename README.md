## Workshop Details
- **Workshop Name:** Chip Design Workshop
- **Organized By:** Gati Shakti Vishwavidyalaya
- **Conducted By:** Entuple Technologies
- **Participants:** ECE 6th Semester Students

## Overview
This repository contains the work, code, and learning materials from the Chip Design Workshop. The workshop focuses on the fundamentals of digital design and introduces hardware description languages and EDA tools used in the semiconductor industry.
